# Chapter 07: Epilogue: What Sticks

## Core Idea
The SUCCESs framework can be applied systematically to improve any communication. The book ends with practical guidance on teaching, strategy, and "unsticking" bad ideas.

## Key Concepts
- **Fight Sticky with Stickier**: You can't "unstick" a false rumor by denying it. You must replace it with an even more memorable competing idea.
- **Sticky Advice sections**: Practical applications for teaching, strategy communication, and idea management.
- **The Goodtimes Virus parody**: An example of fighting sticky (urban legend) with stickier (humorous counter-narrative).

## Key Takeaways
1. Use the SUCCESs checklist as a diagnostic tool for existing messages
2. To fight a sticky rumor, don't deny — replace with something stickier
3. Teaching that sticks uses the same six principles as any sticky idea
4. Any idea can be made stickier — it's engineering, not inspiration
